# IRON COMPASS

iPhone での日常利用を想定した個人向けトレーニング管理アプリ。初期メニューは Priority Full Body A / B / C です。記録はブラウザーの IndexedDB に保存し、毎月のサービス費用やアカウント登録は不要です。

## Windows で起動

Node.js 22.12 以降（24 LTS 推奨）と npm を用意し、PowerShell でこのフォルダを開きます。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示されたローカル URL を開きます。本番ビルドと PWA は次のコマンドで確認できます。

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
npm.cmd run preview
```

Node.js が PATH にない場合、公式ポータブル版の展開先を PowerShell セッションの PATH に追加して同じコマンドを使えます。この作業環境で取得した版の展開先は `.tools/node-v24.11.1-win-x64` です。

## 使い方

1. ホームの「トレーニングを開始」からメニューとジムを選択します。
2. 重量と回数を入力し、完了チェックを付けます。前回の同じセットから値を呼び出せます。重量 0 kg は自重や外部負荷なしの記録に使えます。
3. 「トレーニングを保存」から履歴に登録します。完了した記録を基準に次の A/B/C が決まります。
4. 設定からプロフィール、BIG3目標、種目、ジム、設備、メニューを編集できます。
5. データ移行には設定の JSON バックアップと復元を使います。CSV は完了セットの閲覧や集計向けです。

## 第2段階の使い方

- **コンディション** — ホームから日付を選び、睡眠・疲労・筋肉痛・痛みなどを保存します。履歴から編集できます。参考スコアは保存後に表示し、直前14日間に本セットの記録がある日が2日未満なら算出を保留します。痛み・違和感の入力がある場合は負荷や動作の見直しを促し、コーチのメニュー登録・開始を保留します。
- **成長分析** — 履歴で実測1回重量と推定1RMの推移、直近7日・今月の負荷、種目別頻度、部位別セット数、前回比を確認します。完了本セットだけを集計し、推定式と停滞の条件は画面に記載しています。
- **端末内提案** — コーチでジムと利用時間を選びます。必要な設備は種目マスターで編集できます。追加種目で設備が未設定の場合は提案対象外です。自重で設備不要なら明示的に「設備不要として保存」を選びます。
- **AI相談** — メニュー、レビュー、中長期分析を選び、対象期間を指定します。生成した文章を確認・編集し、コピーして自分で ChatGPT または Claude に貼り付けます。コンディションの自由記述とセットメモは既定で共有に含めません。外部リンクを開くだけでプロンプトは送信されません。
- **AI回答** — メニューは JSON を貼り付け、検証・プレビュー・調整後に確認を入れて登録します。レビューと中長期分析は回答テキストを相談日とともに保存できます。登録した提案を選ぶと、重量・回数などを入力済みの新しい下書きを作成できます。

同じURLで第1段階から更新すると、既存の IndexedDB に追加テーブルが作成されます。JSONバックアップは第1段階と第2段階の両形式を読み込めます。復元は全体の置き換えなので、第1段階のバックアップを復元すると第2段階の追加データは空になります。

## iPhone とデータ保存

iPhone でホーム画面に追加するには、HTTPS で配信したビルドを Safari で開き、共有メニューから「ホーム画面に追加」を選びます。オフライン利用を始める前にオンラインで一度開いてください。開発サーバーでは Service Worker を有効にしていません。設定画面に現行バージョンを表示し、更新は通知から手動で実行します。

GitHub Pagesでは手動のActionsワークフローで `dist/` を配信します。画面のURLはハッシュを使うため、たとえば `/iron-compass/#history` は再読み込みできます。PCとiPhoneのデータは自動同期されません。端末やURLを変更する前に、設定からJSONをダウンロードするか「共有・ファイルに保存」を使って移行してください。ブラウザーのサイトデータを消すと記録も削除される場合があります。

公開用の初期データは編集用サンプルで、既存のデータベースでは初期化を再実行しません。個人初期設定、バックアップ、環境設定は公開リポジトリと配布物に含めず、ローカルの `.private/` に保管します。

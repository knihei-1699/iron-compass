# 要件

## 第1段階

日本語のモバイルファースト UI から、ホーム、記録、履歴・分析、AIコーチ、設定の各画面へ移動する。記録画面で A/B/C とジムを選び、種目とセットを編集して完了した実績を登録する。下書きは再読み込み後に復元する。履歴から登録済み記録を編集・削除できる。

設定からプロフィール、BIG3目標、登録自己ベスト、ジムと設備、種目、A/B/Cプラン、休憩時間を管理する。公開版のプロフィールの数値、目標、メニュー、ジムは編集用のサンプルで、初期実績は空とする。

設備一覧は利用者が変更できる。

データは端末内の IndexedDB に保存する。バックアップの復元前に形式・値・参照を検証し、置き換え前に利用者に確認する。JSON と CSV を端末に出力できる。

## 第2段階

完了本セットを対象に、BIG3、実測と推定1RM、前回比、参考の停滞傾向、種目・部位の週間セット数、週間・月間の負荷、種目別頻度を表示する。実績のない項目はグラフを描画しない。

日次コンディションの入力、履歴、編集を提供する。参考スコアには睡眠・疲労・ストレス・意欲・筋肉痛と運動間隔・週間負荷を使い、内訳を表示する。痛みや違和感がある日はスコアにかかわらず提案メニューの負荷を保留する。

コーチ画面はA/B/C順序を保ち、ジム設備、実績、利用時間、優先部位、当日の状態に基づく端末内提案を生成する。外部AI相談は3モードと対象期間、事前編集、手動コピーを提供する。メニューの回答はJSONとして検証し、プレビューと確認後に登録する。レビューと中長期分析は日付・相談種類とともに保存する。

## 第3段階

公開用の初期データと非公開の個人設定を分離する。初回の汎用データは同じオリジンに保存済みの設定や記録を書き換えない。端末間はJSONで移行し、復元には置き換えの確認を求める。

GitHub Pagesでプロジェクト配下の直接アクセス、再読み込み、オフライン利用を可能にする。配信は手動起動し、ビルドとテスト、配布物検査が成功した場合に限る。iPhoneのホーム画面追加、セーフエリア、入力時の表示、ファイルの保存・復元を支援する。新バージョンは通知し、トレーニングの下書きと履歴編集中は更新を保留する。
